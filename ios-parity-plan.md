# iOS → Android: что изменилось на iOS после сборки 1 в TestFlight

Источник: prizrak-box-apple, 99 коммитов после `7121fb0` (последний коммит
перед архивом 1.1 (1) от 18.10.2026 22:46) до `86448a3`.
Цель: этот репозиторий, ветка `prizrak` (`40cc4ad`, 14.10.2026), работа идёт
в ветке `ios-parity`.

Android сейчас, для справки: Jetpack Compose (`design/.../compose`),
Material 3 с синим основным цветом (`#1A5FAC`), Главная = `MainScreen`
(шапка с логотипом профиля, одна `MainProfileCard`, `GhostPowerButton`,
группы прокси), профили — на отдельном экране (`ProfilesScreen`), на широких
экранах — `AppNavigationRail`. Меню отладки нет (15 нажатий на логотип
открывают тему «Всегда лето» с огурчиком на фоне окна). Встроенной
панели (dashboard) нет, WebView нет.

Обозначения: **новое** — на Android нет; **доработать** — на Android есть
свой вариант, привести к iOS; **проверить** — на iOS сделано «как на
Android», сверить и закрыть; **—** — только для iOS.

---

## Решения (ответы на вопросы)

1. **Акцент.** Текущие основные цвета Android (синий `#1A5FAC`, зелёная
   схема «Лета») убираются. Цвет акцента работает как на iOS: по умолчанию
   цвет карточки активного профиля, либо выбранный из списка, либо свой
   (Персонализация).
2. **«Всегда лето».** Текущая реализация удаляется целиком (зелёная схема,
   `summerModeUnlocked`, `bg_summer_cucumber`, пасхалка на логотипе).
   Вместо неё — фоны и акценты как на iOS, «Огурчик» становится обычным
   фоном Главной.
3. **Вход в «Отладку».** 10 нажатий на версию в «О программе», как на iOS.
   Пасхалка на логотипе Главной убирается.
4. **«Мушрумия» на старых Android.** Настоящее размытие стекла — с API 31
   (Android 12), ниже — полупрозрачные карточки. Согласовано.
5. **Планшеты и складные.** Планшеты — как iPad. Складные смартфоны — как
   iPhone Duo, но без бокового меню переключения Главная/Настройки (на
   Android оно там не нужно); прочие нюансы Android — по ходу работы.

## Фаза 1 — данные и логика (мало кода, низкий риск)

Итог фазы 1:
- `pxa-theme` хранится в `profile_links.json` вместе с остальными заголовками
  профиля (миграция Room не нужна); разбор — `ProfileTheme`, `Profile.theme`.
- 2099 и позже = без срока, `total=1` = безлимит и для напоминаний о трафике
  (было: любой расход давал «использовано больше 100 %»).
- Удаление активного профиля делает активным соседа по списку (на Android нет
  «последнего использованного» до колоды в фазе 6); запущенный туннель
  останавливается, как на iOS. Главная выбирает первый сохранённый, если активного нет.
- «Обновлено» в будущем на Android не бывает (отрицательный интервал = «недавно»).
- 3c4860f к Android не относится: лёгкой проверки профиля перед импортом нет.

- Скрытие `external-controller`/`secret` в «Переопределении» — вместе с

- «Автоматическое отключение» проверено вживую после фазы 7 (через Zashboard).
  Нашлись две ошибки, исправлены: ядро (наследство CMFA) само закрывало
  соединения группы в `PatchSelector` при любом выборе — переключатель ни на
  что не влиял, исключения для LoadBalance/Smart и того же узла обходились;
  теперь закрывает только приложение по переключателю. И `queryConnections`
  падал на `"connections": null` (нет соединений). Включено — `mtalk.google.com`
  через «VPN» закрыт при смене узла (closed 1); выключено — остаётся на старом.
- Проверено вживую: mipstack + BBR (в логе ядра `"congestion-controller":"bbr"`),
  статус и память при работающем туннеле.

### 5.1 Настройки — новая структура

Вместо текущих групп (Общие: Приложение, О программе; Ядро: Сеть,
Переопределение, Функции Мета, Логи; Активный профиль: Правила, Провайдеры,
Соединения):

- **Справа вверху** — круглая кнопка ⓘ, открывает «О программе».
- **Устройство**
  - Язык
  - Визуал — как на iOS (фаза 2)
  - Уведомления — текущий раздел Android
  - Сеть — текущий раздел Android, без стека TUN (он уходит в «Отладку»)
- **Активный туннель** (пока туннель запущен)
  - Правила — текущая реализация Android
  - Провайдеры — текущая реализация Android
  - Соединения — текущая реализация Android
  - Zashboard — только если включён в «Отладке» (фаза 7)
- **О приложении**
  - Версия приложения
  - Ядро
- **Диагностика**
  - Логи сессий — открывает текущий раздел «Логи»
  - Статус VPN — копия iOS
  - Память — только текущее потребление, без лимита 50 МБ

`SettingsDestination` / `SettingsList` в `SettingsScreen.kt` переделываются
под эту структуру; раздел «Приложение» (`AppSettingsScreen`) расходится по
«Визуалу», «Языку» и «Отладке».

### Широкие экраны (решение 5)

Как на iOS сейчас (`PBI/Application.swift`, `AppNavigation.swift`,
`DashboardView.swift`, `ProfileDeckList.swift`, `SettingsTab.swift`;
дизайн — `ipad-iphone-duo-plan.md` §5):

- **Правило включения — по ширине окна, не по устройству:** две колонки при
  ширине окна ≥ 600 dp (на iOS — `horizontalSizeClass == .regular`). Уже
  этого — раскладка телефона. Планшет и складной различаются только
  наличием сгиба (`FoldingFeature` из Jetpack WindowManager).
- **Планшет (как iPad):** сверху «таблетка» Главная · Профили · Настройки,
  справа от неё красный ⏻ при подключении; нижней панели нет.
  - Главная — две колонки: слева всё как на телефоне (шапка с ＋/↻, колода,
    карточка, питание, группы), справа — узлы выбранной группы (сортировка,
    проверка задержки); открытый из колоды профиль — тоже справа, с ✕.
    Отключено — справа заглушка «Прокси-группы появятся после подключения»
    и объявление профиля целиком. Простой режим — справа узлы первой группы.
    Нет профилей — одна колонка, приветствие.
  - Профили (вкладка только на планшете) — слева все профили полосками
    (↻, ＋, перетаскивание), справа открытый профиль; по умолчанию активный.
  - Настройки — слева разделы, справа выбранный раздел; пусто — «Выберите
    раздел». Разделы на Android — отдельные Activity, поэтому две колонки —
    через Activity Embedding (Jetpack WindowManager): правила пар
    «Настройки → раздел», заглушка справа, без стрелки «назад» в правой
    колонке.
- **Складной (как iPhone Duo, без бокового меню):** внизу та же панель
  Главная · Настройки, что на телефоне; вкладки «Профили» нет — профили
  в колоде на Главной, открытый профиль справа. Главная и Настройки — две
  колонки, граница — по сгибу. Сложен (внешний экран) — телефон.
- **Сгиб поперёк (полураскрыт «ноутбуком»):** колонки встают одна над
  другой и делятся по сгибу — сверху колода и карточка (в Настройках —
  список), снизу, на половине, что лежит на столе, правая колонка и панель
  Главная · Настройки. На сгиб ничего не ложится. Плоско раскрытый сгиб
  поперёк — просто складка, раскладка обычная.
- **Кнопка подключения в две колонки** (планшет, раскрытый складной,
  «ноутбук»): вверху правой колонки, пока VPN выключен; левая — только
  карточки.
- **Смена ширины** (сложили/разложили, изменили окно): выбранная группа,
  открытый профиль и раздел настроек сохраняются; вкладка «Профили» при
  переходе в узкое окно — Главная с развёрнутой колодой.
- Android TV не меняется (у него своя боковая панель).
- Эмуляторы: `PrizrakTablet` (Pixel Tablet), `PrizrakFold`
  (Pixel 9 Pro Fold), Android 15.

## Фаза 7 — Zashboard

Итог фазы 7:
- Отладка → Zashboard (выключен по умолчанию): ядро открывает контроллер
  `127.0.0.1:9090` с постоянным секретом Zashboard (создаётся при первом
  включении). Пока включён — это единственный контроллер: в ядре
  (`patchZashboard` после `patchOverride`) заменяются `external-controller`,
  TLS/unix/pipe очищаются, CORS — по умолчанию; контроллер профиля тоже
  уступает. Группа «Внешний контроллер» в «Переопределении» при включении
  сбрасывается (адрес, TLS, CORS, secret) и заблокирована с пояснением;
  подтверждение говорит, что сбросится и что VPN перезагрузит конфигурацию.
  Включение/выключение перезагружает конфигурацию без перезапуска туннеля.
- Настройки → Активный туннель → Zashboard: `ZashboardActivity` во весь экран
  (полоса под строкой состояния — цвет верха страницы). Страница —
  `app/zashboard/assets/zashboard` из APK по
  `https://appassets.androidplatform.net/zashboard/`, без service worker;
  язык приложения — первый язык панели; высота страницы задаётся сами
  (`--app-height`: в WebView 100dvh = 0, если страница начала грузиться до
  разметки). Консоль страницы — в логе приложения.
- Круглое перетаскиваемое меню (одно место на всех экранах): Свернуть /
  Показать, Главная, Настройки, Закрыть, Остановить VPN; свёрнутая страница
  живёт (тот же WebView), кнопка — поверх экранов приложения. «Назад»
  сворачивает. Остановка VPN закрывает Zashboard.
- О программе: строка «Zashboard vX» при включённом, ссылка «Zashboard (MIT)»
  в источниках. Отладка → «Очистить данные Zashboard» (сброса на Android нет).
- Задача Gradle `updateZashboard` перед `preBuild`: последний релиз,
  проверка SHA-256, без сети — старая копия (`app/zashboard/README.md`).
